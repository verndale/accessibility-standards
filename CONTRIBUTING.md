# Contributing

1. Add or revise source records and their evidence routes.
2. Preserve stable IDs and declare every semantic dependency.
3. Add tests or golden fixtures for behavior changes.
4. Run `pnpm verify:ci`, `pnpm wiki:check`, and `pnpm graph:check`.

Use Conventional Commits. Authority/schema/behavior breaks require a major release; additive stable records are minor; editorial corrections are patch.
